# Sophia's Daily Integration Log

One folder. Three files. That's it.

- `2026-09.md` — the running log. Everything reported, with times. One month per file.
- `system.md` — the daily system and The Way Out, so any session can pick up cold.
- `science.md` — the real studies behind each piece, for when you ask "why."

## Rules of the log
- Log what got done, with the time it was reported. One line each.
- No scores, no counts, unless asked. The streak is the only score.
- A missed day means run today's reps. No catch-up. No shame.
- Done beats good.

## How a session goes
1. You name the task.
2. You get a short numbered list. Only the needed steps.
3. You report. It gets logged with the time.
4. Defeated? You get reminded what you already did today. No lecture.
