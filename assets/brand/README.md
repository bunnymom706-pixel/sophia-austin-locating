horizontal "SPIRIT / REAL ESTATE GROUP" lockup with the gold flame). The flyers in `flyers/` pick it up automatically;
until it exists they rebuild the logo from HTML/SVG (Montserrat wordmark, navy #0F2D5C, flame #F2A93B).
